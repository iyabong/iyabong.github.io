# 클라우드 Windows Server에 IIS 서버 올리기

## 목차

1. 네이버클라우드에 Server 생성
2. 접근 설정
3. IIS 설치
4. 접속 로그 확인

### 1. 네이버클라우드에 Server 생성
[네이버클라우드](https://www.ncloud.com/)

- OS: Windows 2022
- 사양: s2-g3a(vCPU 2EA, Memory 8GB)
  ※ 저장공간: 40GB

### 2. 접근 설정
- Public IP 1개 추가
- ACG 접근 포트 설정
  - 3389 (RDP)
  - 80 (HTTP)

### 3. IIS 설치
RDP Powershell
```powershell
Install-WindowsFeature -Name Web-Server -IncludeManagementTools
```
[Public IP주소]
### 4. IIS 접속 로그 확인
 ※ Log파일 위치: IIS Manager > Server > Sites > Default Web Site > Logging

- RDP 브라우저에서 http://localhost
    GET / - 80
- RDP 밖 브라우저에서 http://[Public IP주소]
    GET / - 80
- GET요청: http://[Public IP주소]/a/b/c.do?p=100
    GET /a/b/c.do p=100
- POST요청: (Powershell) curl -X POST "http://[Public IP주소]/a/b/c.do?p=100" -d "name=test"
    POST /a/b/c.do p=100
